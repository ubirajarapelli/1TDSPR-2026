GIT

Configuração Inicial

git config --global user.name "Seu Nome"
git config --global user.email seu@email.com

Criando um Projeto com Git

Inicializando um repositório

git init

Principais Comandos do Git

Status do repositório

git status

Adicionando arquivos

git add nome-do-arquivo

Fazendo um commit

git commit -m "Adiciona arquivo.txt com mensagem Hello World"

Visualizando histórico

git log

Ciclo de Trabalho do Git

  • Working Directory: Traqueados e/ou Modificados
  • Staging Area: Arquivos adicionados
  • Repository: Arquivos comitados

Branchs

Criar nova branch

git branch nome-da-branch

Alterar de branch

git checkout nova-feature
